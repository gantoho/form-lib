Select 自定义配置示例

展示 labelField、valueField、optionRender、displayField 等功能

示例 1：自定义字段映射（labelField / valueField）

数据格式为 { name, id }，通过 labelField: 'name', valueField: 'id' 映射

示例 2：自定义选项渲染（optionRender）

自定义每个选项的渲染方式，支持 HTML 字符串或 DOM 元素

示例 3：选中显示 value（displayField: 'value'）
